# Корпусные регрессии без полного корпуса

Это короткие дословные выдержки из собственного корпуса, а не дополнительные статьи.
Они нужны, чтобы unit-тесты запускались также в архиве с исходниками без 10 000 документов.
Если исходный файл присутствует, тест проверяет фрагмент непосредственно в нём;
иначе читает соответствующий `.excerpt`. Ожидаемый токен задан независимо от реализации.
Контрольные суммы исходных полных документов сохранены в `provenance.json`.

- `1688.txt`: осмысленный идентификатор «агент 007».
- `2740.txt`: составной числовой компонент стандарта.
- `1.txt`: числа больше 9999 и научное слово длиннее 20 символов.
