# ЛР3. Токенизация

Алгоритм: `funcs/tokenizer.cpp`; правила и независимые примеры — `../tests_lr3_4/TEST_PLAN.md`.
Русские/ASCII-латинские буквы, цифры, внутренние дефисы, нормализация регистра и словарь аббревиатур.
Числа `007` и `7` различаются; стоп-слова сохраняются. Дроби разбиваются; полная Unicode-сегментация не заявляется.

Большой корпус обрабатывается из корня командой `project.ps1 rebuild`. `preprocess_stream.cpp` читает
`data/corpus/texts.tsv` и пишет согласованные потоки токенов и основ, используя прежний токенизатор и русский стеммер.
Исходные тексты экспортируются из существующей PostgreSQL командой `project.ps1 export`.

Маленький пример: `build/labs_3_5/tokenization.exe INPUT_DIR OUTPUT_DIR lab03/abbrevs.txt`.
Входные имена — числовые ID с расширением `.txt`; результат — один токен на строку в `.tokens`.

Измерения всего корпуса — `results/preprocessing_counts.json`, `results/preprocessing.json`.
`lab03/results/benchmark_summary.csv` и `time_vs_size.png` измеряют только алгоритм на подвыборке, без файлового ввода-вывода,
по пяти повторам. Эти два времени нельзя смешивать.
