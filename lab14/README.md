# ЛР14. Сниппеты

Реализация: `src/ir/extensions.cpp` (`build_offsets`, `snippet_json`).
HTML и безопасная подсветка: `lab08/web.py` (`page`).
Формат и ограничения: [описание формата](../src/ir/FORMAT.md).

Статья читается по сохранённому смещению. Выбирается окно до 36 токенов и 280 символов с максимальным
числом совпадений, выводятся исходные словоформы, а не леммы. Отрицательные термины
не подсвечиваются. Сначала экранируется текст, затем добавляется собственный mark.

Показ: обычный запрос в новом веб-режиме после `project.ps1 upgrade`.
CLI возвращает те же фрагменты в `snippet_parts`. Сниппеты не меняют score и состав выдачи.
Тесты: `test_snippet_contains_original_text_and_marks`, `test_html_is_escaped_before_highlight`.
