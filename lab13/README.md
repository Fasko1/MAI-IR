# ЛР13. Ранжирование TF-IDF

Из корня: `.\build\ir_engine.exe search --index data/lab11_index/index.ir --ranked`.

Если запрос содержит только термины через пробелы, выбирается объединение их
списков (неполное соответствие). При явном операторе либо скобках применяется
булево выражение с обычными приоритетами; TF-IDF упорядочивает выбранные документы.

Вес термина: `w(t,d) = (1 + ln(tf(t,d))) * ln(1 + N/df(t))` при `tf>0`, иначе 0.
Вес запроса определяется той же формулой с tf в запросе. Оценка — косинус между
вектором документа и запроса. Норма документа считается по всему словарю при
индексации; норма запроса — по известным терминам в положительном контексте.
Термины под нечётным числом отрицаний и отсутствующие в словаре не участвуют
в ранжировании. Чистое отрицание возвращает допустимые документы с оценкой 0.

Сглаженный IDF выбран явно: даже термин во всех документах имеет ненулевой вес,
а редкий термин получает больший вес. Пустой документ имеет норму 0. Одинаковые
оценки разрешаются сортировкой внешних id. Raw/VB хранят одинаковые tf и нормы,
поэтому сжатие сохраняет оценки и порядок выдачи.
