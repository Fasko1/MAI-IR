# Лабораторная работа №1
## Добыча корпуса документов

### Тематика корпуса

Научные публикации по психологии, образованию
и исследованиям поведения человека.

### Источники

1. PubMed Central (PMC)
2. ERIC

### Цель работы

Исследовать структуру документов будущего корпуса,
изучить их разметку и метаданные, определить способ
выделения основного текста.

### Что необходимо исследовать

- формат исходных документов;
- структуру разметки;
- заголовок;
- авторов;
- дату публикации;
- аннотацию;
- основной текст;
- дополнительные метаданные;
- элементы, которые необходимо исключить из текста.
## Требования

- Python 3.11 или новее
- pypdf 6.19.0

Установка зависимостей:

```bash
python -m pip install -r lab01/requirements.txt
```

## Запуск

Из корневой директории проекта:

```bash
python lab01/run_lab01.py
```

Скрипт последовательно:

1. обрабатывает пример документа PubMed Central;
2. обрабатывает пример документа ERIC;
3. рассчитывает статистику;
4. запускает автоматические тесты.

## Результаты

Результаты обработки сохраняются в каталоге:

`lab01/results/`

В результате работы создаются унифицированные JSON-документы
для обоих исследуемых источников.
