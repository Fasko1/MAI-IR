# Анализ документов ERIC

## Пример документа

**ERIC ID:** EJ854309

**Название:**  
The Causal Ordering of Self-Concept and Academic Motivation and Its Effect on Academic Achievement

**Тематика:**  
Академическая мотивация, самооценка и образовательная психология.

## Формат исходных данных

Для публикации используются два типа данных:

- карточка публикации ERIC содержит метаданные;
- полный текст публикации представлен в формате PDF.

В отличие от PubMed Central, где метаданные и полный текст
находятся в одном XML-документе, в ERIC они могут храниться
раздельно.

## Метаданные

Для документа могут быть выделены:

- ERIC ID;
- название;
- авторы;
- дата публикации;
- язык;
- тематические дескрипторы;
- количество страниц.

## Основной текст

Основной текст извлекается из PDF-файла.

При обработке PDF текст извлекается постранично,
после чего удаляются лишние пробелы.

В будущем при обработке корпуса необходимо учитывать,
что PDF может содержать:

- номера страниц;
- колонтитулы;
- таблицы;
- подписи к рисункам;
- список литературы.

Такие элементы могут создавать шум в поисковом индексе.

## Выделение текста

Для дальнейшего использования документ приводится
к единому формату JSON со следующими полями:

- `id`;
- `source`;
- `title`;
- `authors`;
- `publication_date`;
- `keywords`;
- `abstract`;
- `text`.
