# План тестирования

Цель тестирования — проверить корректность выделения данных
из исходных документов PubMed Central и ERIC, а также приведение
документов разных источников к единому формату.

## Тест 1. Проверка идентификатора PMC

Проверяется, что из исходного XML-документа PMC корректно
извлекается идентификатор статьи.

Ожидаемый результат:

`PMC8935530`

## Тест 2. Проверка идентификатора ERIC

Проверяется, что для документа ERIC корректно сохраняется
идентификатор публикации.

Ожидаемый результат:

`EJ854309`

## Тест 3. Проверка названия PMC

После обработки исходного XML-документа поле `title`
не должно быть пустым.

## Тест 4. Проверка названия ERIC

После обработки документа ERIC поле `title`
не должно быть пустым.

## Тест 5. Проверка авторов PMC

Список авторов обработанного документа PMC
должен содержать хотя бы одного автора.

## Тест 6. Проверка авторов ERIC

Список авторов обработанного документа ERIC
должен содержать хотя бы одного автора.

## Тест 7. Проверка основного текста PMC

Размер выделенного основного текста должен превышать
1000 символов.

Это позволяет выявить ситуацию, когда вместо полного текста
была извлечена только небольшая часть документа.

## Тест 8. Проверка основного текста ERIC

Размер выделенного текста должен превышать
1000 символов.

Это позволяет проверить, что текст был успешно извлечён
из PDF-документа.

## Тест 9. Проверка единого формата документов

Для обработанных документов обоих источников проверяется
наличие следующих полей:

- `id`;
- `source`;
- `title`;
- `authors`;
- `publication_date`;
- `keywords`;
- `abstract`;
- `text`.

Наличие единого набора полей позволяет использовать документы
из различных источников совместно в последующих лабораторных работах.

## Результат тестирования

Все 9 тестов успешно пройдены.
