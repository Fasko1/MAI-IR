# ЛР7. Булев индекс

Собственное C++ ядро расположено в `src/ir/`; общие структуры вынесены в
`base.h`, формат и интерфейс описаны в `src/ir/API.md`.

Индексатор читает манифест `id<TAB>path<TAB>title<TAB>url` и подготовленные
стеммы. В каждом документе сортируются идентификаторы терминов, считается tf.
Пары `(term, doc, tf)` сбрасываются отсортированными сериями на диск и сливаются
собственной минимальной кучей. Корпус целиком в оперативную память не загружается.
В памяти остаются словарь, метаданные документов, один документ и ограниченный
буфер серий. Это внешняя сортировка, а не сортировка всего корпуса в памяти.

`ir_engine build --manifest data/index_manifest.tsv --index data/index.raw`

Для большого корпуса: `ir_engine build --inline --manifest data/corpus/stems.tsv --index data/lab07_index/index.ir`.
В режиме `--inline` второе поле содержит термины через один ASCII-пробел вместо пути к файлу;
остальные поля и бинарный формат индекса совпадают. Пустое поле терминов сохраняет пустой документ.

Индекс содержит обратные списки `(docID, tf)` и прямую таблицу документов:
внешний id, заголовок, URL, длину и норму TF-IDF. Внешний id не преобразуется
в число: `007` сохраняется. Внутренние docID определены порядком манифеста.
Повторяющиеся внешние id отклоняются. Все размеры и границы проверяются;
после построения выполняется полная проверка индекса.
