# ЛР8. Булев поиск

Из корня: `.\build\ir_engine.exe search --index data/lab11_index/index.ir` читает запросы UTF-8 из stdin,
один запрос на строку, и выдаёт JSONL в stdout. Есть однократный режим
`--query "геном && !вирус"`, пагинация `--limit 50 --offset 0`.

Синтаксис: пробел/`AND`/`&&`, `OR`/`||`, `NOT`/`!`, скобки. Приоритет:
отрицание, конъюнкция, дизъюнкция. Списки пересекаются и объединяются линейным
слиянием; отрицание берётся относительно всех документов, включая пустые.
Неизвестный термин даёт пустое множество. Синтаксическая ошибка возвращается
в поле `error`; следующая строка потока продолжает обрабатываться.

Запрос проходит тот же токенизатор и стеммер, что корпус. По умолчанию
стоп-слова не удаляются. Если корпус создан со стоп-фильтром, тот же список
передаётся через `--stopwords`. Нельзя менять профиль обработки только у
запроса: иначе совпадение с индексом перестанет быть воспроизводимым.

Результаты булева поиска сортируются по внешнему id побайтово; `count`
и `total` содержат полный размер множества, `results` — только страницу.

Веб: `project.ps1 web`, затем <http://127.0.0.1:8080>. Индекс загружается один раз в постоянный C++-процесс;
HTML показывает заголовки/ссылки, по 50 результатов и следующие страницы. Остановка — Ctrl+C.
