# ЛР12. Прыжки по сжатым спискам

Реализация: `src/ir/skips.cpp` (`build_skips`, `open_skips`, `intersect_skips`).
Точки перезапуска сохраняют предыдущий doc-ID и смещение для пропуска декодирования VB.
Формат и ограничения: [описание формата](../src/ir/FORMAT.md).

`make-skips --step N` строит таблицу с фиксированным шагом, 0 означает корень из DF.
`search --skip-index FILE` подключает таблицу; `--no-skips` включает контрольный обход,
`--profile` добавляет время и счётчики. Обычная выдача без профилирования воспроизводима.

Измерения с отдельными обучающим и тестовым пулами: `tools/benchmark_advanced.py`.
Результат: `results/advanced/skip_benchmark.json`. Меньшее число сравнений не подменяет замер времени.
