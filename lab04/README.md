# ЛР4. Стемминг

`funcs/stemmer.cpp` — самостоятельная реализация русского Snowball/Porter на C++ без STL.
Примеры: `чтение → чтен`, `клетки → клетк`; `клеток` остаётся `клеток`.
Основа не обязана быть словарным словом. Словарная лемматизация реализована отдельно в новом режиме: см. [README](../README.md).

Малый пример из корня: `build/labs_3_5/stemming.exe INPUT.tokens OUTPUT.stems [STOPLIST]`.
Пакет отдельных файлов: `stemming.exe --batch MANIFEST OUTPUT_DIR`.
Большой корпус: `project.ps1 rebuild`, поток `data/corpus/stems.tsv`.
На основном пути STOPLIST не используется; число вхождений токенов и основ должно совпадать.

`audit_stream.cpp` повторно читает сохранённые потоки и проверяет IDs/метаданные/выравнивание;
результат — `results/stemming_audit.json`. Старый `audit.cpp` сохраняется для файловых примеров.
Официальные 49 785 тестовых пар лежат в `tests_lr3_4/reference`, это данные для проверки, а не код реализации.

`evaluate_stemming.py` сравнивает AND-поиск до/после стемминга на прежних двух размеченных пулах.
Результаты — `results_snowball`; `review_10000/review_10000.csv` — неизменённые исторические оценки.
Они основаны на ИИ-разметке и не оценивают качество поиска на всём новом корпусе.
