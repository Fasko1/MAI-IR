# ЛР5. Закон Ципфа

`zipf_count.cpp` считает корпусные вхождения в собственной хеш-таблице и выполняет сортировку слиянием.
`zipfs_law.py` запускает C++ и рисует уже рассчитанные частоты. Ципф: `f(r)=f(1)/r`, ранг начинается с 1.
Показываются первые 10 000 рангов; частоты посчитаны по всему словарю. Мандельброт — необязательное задание, не заявляется.

Большой корпус: `project.ps1 rebuild`, либо после готовой обработки
`.venv/Scripts/python.exe lab05/zipfs_law.py --stream`.
Старый режим без `--stream` читает отдельные файлы `data/lab03_tokens`/`data/lab04_stems` и предназначен для прежнего малого экспорта.

Результаты: `results/tokens` и `results/stems` внутри этой папки — `freq.txt`, `stats.json`, `zipf.png`.
Для IDF нужна документная частота DF; она отличается от CF, используемой здесь.
План независимых проверок частот — `tests_lr7_13/test_zipf.py`, потокового входа — `test_stream.py`.
